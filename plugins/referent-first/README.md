# referent-first

名前（label）より先に、実体（referent）を決めてから書くための plugin。実体は名前が表す具体的な物や事柄（設定、コマンド、条件、事象、状態など）を指す。どの返信でも常に守る rule と、対象文書で本文より先に表記確定表を作る skill の2つで成り立つ。実体と役割を決めてからすでにある名前を探して使い、不要な造語、作業ラベル、短縮語、同じ物の言い換えを防ぐ。

## 基準

1. **名前より先に実体を決める**：対象文書では4列の表記確定表を本文より先に別ファイルに保存してから本文を書き、短い物では書き始める前に実体と使う名前を会話の中で先に決めてから書く。
2. **作業ラベルと1語の総称を置かない**：骨組み、見出し、表の列見出し、チェックリスト、結論に「観測をまとめる」のような作業ラベルや、「作業者」「相手」「動く所」「対象」のような1語の総称を置かない。
3. **新しい呼び名と短縮語を作らない**：名前のある物はそのまま繰り返し、同じ物を別の語に言い換えない。新しい名前が本当に要るときだけ表記確定表で実体と役割を先に決めてから付け、初出で定義する。

## 適用範囲

`SKILL.md` の `description` には、返信や文書、図を書く前に4列の表記確定表を保存することと、チャットやスレッドの返信でも調べた結果や原因の報告、仕組みの説明、案の比較と対策の提案を書く前に毎回呼ぶことを記している。これらに該当する作業や、ユーザーが示した推論の順序を見出しやラベルにまとめるときにエージェントがこの skill を読み込む。ユーザー原文の引用、単純な機械編集、既存名だけを再利用する箇所、表現だけの推敲は対象外。

## 名前を探す先と造語が出やすい箇所

- **名前を探す先**：プロジェクト指示、skill、コード・設定・コマンド、製品の画面、製品やツールの説明の原文、用語集、ユーザーの発言、公的名称や定着した専門用語、一般的な日本語。
- **探す先に含めない文**：ほかのセッション、サブエージェント、ほかの AI が書いた文や、作業中に自分が書いたメモ・作業記録・結果の表にある呼び名は、既存名の根拠にしない。
- **同じ物の言い換えと比べる物の呼び名**：同じ物を返信や表をまたいで別の語に言い換えない。修正の前と後、2つの案、2つのブランチのように比べる物も「版」「新」「旧」「案A」と呼ばず、どのブランチのどのファイルか、何を変えた物かで書く。

## 短い物を書く手順

返信、進捗チェックリスト、PR の説明、issue、依頼文では、書き始める前に扱う実体と使う名前を会話の中で先に決め、本文、題名、見出し、表、チェックリストのすべてで同じ名前を繰り返す。

## 対象文書で表記確定表を先に作る手順

調べた結果や原因の報告、仕組みの説明、案の比較、対策案、設計資料を書くときと新しい名前を決めるときは、本文と図より先に4列の表記確定表（実体、役割、出典の表記、本文と図で使う表記）を作る。左の3列を埋めてから4列目の表記を決め、別ファイルに保存してから本文と図を書き、送る前に本文と図の表記を表と突き合わせる。

## 環境ごとの読まれ方

この plugin は、常に読む rule と対象文書で読む skill（`skills/referent-first/SKILL.md`）の2つで成り立つ。環境ごとの読まれ方は次のとおり。

- **Antigravity**：`rules/AGENTS.md` を毎ターン常に読み込み、対象文書では `skills/referent-first/SKILL.md` を読む。
- **Claude Code**：plugin の `rules/` は読まず、skill の description に当たる作業で `skills/referent-first/SKILL.md` を読む。毎回の返信で rule を効かせたいときは、プロジェクトの `CLAUDE.md` か `.claude/rules/` に `rules/AGENTS.md` と同じ文を置く。
- **claude.ai のチャットと Cowork**：`rules/AGENTS.md` を読まず、`skills/referent-first/SKILL.md` だけを読む。

## 入れ方

Claude Code：

```sh
/plugin marketplace add u-ichi/agent-plugins
/plugin install referent-first@u-ichi
```

claude.ai、Agent Plugins に対応したツール、または skill 単体での導入手順はリポジトリの [README](../../README.md#入れ方) を参照。

## ファイル構成

```
plugin.json                                  Agent Plugins の manifest
.claude-plugin/plugin.json                   Claude Code の manifest
rules/AGENTS.md                              Antigravity が毎ターン常に読む rule（frontmatter なし）
skills/referent-first/SKILL.md               skill の本文（適用判定、4列の表記確定表の作り方と保存、送る前の照合）
```
